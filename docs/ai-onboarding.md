# AI onboarding

Maintain a trustworthy work record, not an inferred activity feed. The application indexes deliberately authored Markdown. The companion skills turn that evidence into a morning briefing, a mid-session update, or an end-of-session handoff.

Read [../AGENTS.md](../AGENTS.md), then inspect the active source configuration. Do not assume the tracked example is the live workspace. Remain within configured roots.

For application work, trace the relevant route through `server.mjs`, `lib/`, `public/`, and `test/`. For journal work, read [../AUTHORING.md](../AUTHORING.md), affected tasks, the current journal, and relevant linked references.

## Reasoning contract

- Count older open work too.
- Update dates are not due dates.
- Code or a plan does not establish acceptance.
- A blocker remains until evidence says it cleared.
- Suggestions and handoff next steps are not execution authority.
- Do not mine other chats, mail, calendars, repositories, or unrelated filesystem locations unless the user authorizes that source.

Use `start-day` for a read-only briefing, `update-journal` for meaningful mid-session progress, and `tidy-up` for end-of-session reconciliation. See [skills.md](skills.md).
